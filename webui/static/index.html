使用指南

  1. 选择场景和配置

    从仓库模板开始。集体通信选择算法与物理拓扑，多节点场景还需设置节点数和节点间链路。

  2. 调整参数，检查预览

    链路字段写入本次实验的 [stack] 覆盖。也可以导入或编辑完整 .cfg 和 .profile；原文件不会被修改。

  3. 运行并查看结果

    服务器调用构建好的 gpu-cluster-sim。只有 status=complete 的结果会进入延迟对比；运行上限和取消操作会停止对应进程。

  4. 对比和导出

    在运行记录中选择 2–6 个已完成实验。下载包包含输入、原始日志、结果字段、步骤 CSV 和程序版本。

第一次使用 
./ns3 build gpu-cluster-sim
python -m webui --port 8080

步骤时序来自实际 trace；没有记录该数据的场景会显示为空。
