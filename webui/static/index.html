User guide

  1. Choose a scenario and configuration

    Start with a repository template. Choose a collective algorithm and physical topology. For multiple nodes, set the node count and inter-node links.

  2. Adjust inputs and check the preview

    Link fields become [stack] overrides for this run. Import or edit .cfg and .profile text for custom experiments. Each run uses its own input snapshot.

  3. Run and inspect the results

    The server executes the built gpu-cluster-sim binary. Only status=complete results enter latency comparisons. Cancellation and timeouts stop the corresponding process.

  4. Compare and export

    Select 2–6 completed runs in the history. Download an archive with the inputs, raw log, result fields, step CSV, and program version.

First run 
./ns3 build gpu-cluster-sim
